Ingestion path — step by step

Claude Code Hooks
  • post_tool_use fires after every tool call (Bash, Read, Edit, etc.) and POSTs the tool input/output to /agentmemory/observe
  • notification fires for agent-level events (session start, user messages)
  • Hook payload includes: project, sessionId, hookType, toolName, files[], raw content
Privacy Filter (Go)
  • Strips <private>…</private> blocks before any write
  • Regex-redacts API keys, JWTs, key=value secret patterns
  • Strips ANSI escape codes from terminal output
  • Sets HasSecrets=true flag → downstream LLM enrichment is skipped (FR-9)
  • Fail-closed: if filter errors, observation is dropped
Dedup + Queue (Go)
  • SHA-256 hash of content checked against a rolling 5-minute window per session
  • Duplicate → dropped silently, dedup counter incremented in Prometheus
  • Unique → stored as RawObservation (compressed=0) in PostgreSQL
  • Job enqueued: memory queue (dev) or RabbitMQ (prod, QUEUE_BACKEND)
Python /compress
  • Worker POSTs raw observation to Python /compress
  • LLMCompressor sends to Bifrost with XML-structured output prompt → returns narrative, concepts[], files[]
  • If Bifrost unreachable → synthetic_compressor extracts first 3 sentences as fallback
  • Python POSTs result back to Go POST /internal/observation/{id}/compressed
  • Go sets compressed=1, fires IndexBus → BM25 + vector re-index
Consolidation Pipeline (Go, session end)
  • Triggered by session_end hook → POST /agentmemory/session-end
  • Step 1: fetch all compressed observations for session
  • Step 2: POST /summarize to Python → SessionSummary
  • Step 3: POST /extract per observation → entities + relationships → graph_entities
  • Step 4: Go-side distilMemories() → creates Memory rows in PostgreSQL
  • Each step is best-effort — one failure doesn't abort the rest
Hybrid Search (Go)
  • POST /smart-search or MCP smart-search tool
  • BM25: inverted-index keyword search over compressed narratives
  • Vector: query text → Python /embed → Bifrost embedding model → cosine similarity
  • Graph: entity BFS via Neo4j (optional, ADR-0003)
  • Results fused with Reciprocal Rank Fusion k=60, per-session diversity cap=3
  • Returns ranked hits with scores from all active indexes
MCP Server (Go, port 3114)
  • Streamable HTTP transport, spec 2025-06-18
  • 6 tools today: remember, recall, forget, smart-search, session-history, status
  • Tool handlers are thin wrappers — call same store + search functions as the REST API
  • Also mounted at /agentmemory/mcp on the main API (:3111)
  • Standalone MCP binary: cmd/mcp
Decay Engine (Go, nightly)
  • Runs on a nightly scheduler (Go time.AfterFunc)
  • For each memory: strength *= DECAY_RATE_PER_DAY ^ daysOld (Ebbinghaus curve)
  • Default rate: 0.95/day · eviction threshold: 0.1
  • Memories below threshold → hard-deleted from PostgreSQL
  • Recalling a memory (recall MCP tool) reinforces its strength

Key configuration

Variable Default Effect on data flow
QUEUE_BACKENDmemoryIn-process queue (jobs lost on restart) vs RabbitMQ for prod
BIFROST_URLrequiredWithout it the service won't start; drives /compress /summarize /extract /embed
EMBEDDING_MODELunsetIf unset → local hash fallback instead of real vector embeddings
LLM_MODELunsetModel for all LLM stages; per-stage overrides: COMPRESS_MODEL, SUMMARIZE_MODEL, EXTRACT_MODEL
NEO4J_ENABLEDfalseGraph search leg disabled by default; service runs in degraded mode (ADR-0003)
AGENTMEMORY_SECRETemptyEmpty = auth disabled. Set to require Bearer token on all /agentmemory/* routes
DECAY_RATE_PER_DAY0.95Ebbinghaus base; lower = faster forgetting
DECAY_EVICTION_THRESHOLD0.1Memories below this strength are hard-deleted nightly
PYTHON_SERVICE_URLhttp://localhost:5000Go → Python callback URL for compress/extract/summarize/embed
