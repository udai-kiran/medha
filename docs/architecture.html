Two services, one system. The Go API handles all hot-path operations (ingest, search, state). The Python sidecar is called for LLM and embedding work through Bifrost/OpenRouter. Compression is async after observation ingest; prompt recall is synchronous and therefore has stricter filtering and timeout behavior.

4. Prompt Recall Path

UserPromptSubmit hook │ ▼ agentmem-recall-hook │ POST /v1/agentmemory/recall-summary │ timeout: 20s, threshold: max relevance >= 0.01 ▼ Go RecallSummaryHandler │ ├─ hybrid search overfetches (min 20, then trims to requested limit) │ ├─ hydrate rows from PostgreSQL │ ├─ prompt-facing cleanup │ • drop unhydrated empty hits │ • drop raw tool traces: Bash | {...}, Edit | {...}, Read | {...} │ • drop empty notification observations │ ├─ Python /summarize-memories if available │ └─ bullet fallback if summarizer is down ▼ hookSpecificOutput.additionalContext │ ▼ Claude sees: "[agent-mem] Relevant context from memory: ..."

/smart-search remains a raw debugging/search endpoint. The cleanup above is intentionally scoped to /recall-summary, because that endpoint is what the Claude hook injects into the user prompt.

5. Search Pipeline (Hybrid RRF)

Query: "how does JWT auth work" │ ┌─────────────────┼─────────────────┐ ▼ ▼ ▼ PgFTS Vector Graph tsquery & cosine sim entity BFS ts_rank (/embed) (Neo4j or PG) bounded by HYBRID_VECTOR_TIMEOUT_SEC │ │ │ ▼ ▼ ▼ result set result set result set (token match) (semantic) (entity links) │ │ │ └─────────────┬───┴─────────────────┘ │ ▼ Reciprocal Rank Fusion k=60, score = 1/(k + rank) │ ▼ Post-Fusion Multipliers ┌─────────────────────────────────────┐ │ provenance boost: user 2.0× > │ │ extracted 1.0× > episodic 0.7× │ │ │ │ recency boost: │ │ 1 + weight · exp(-age · ln2 / HL) │ │ weight=0.3, halfLife=7d │ └─────────────────────────────────────┘ │ ▼ Optional Cross-Encoder Rerank (Cohere rerank-4-fast via Bifrost) │ ▼ Per-Session Diversity Cap (max 3) │ ▼ Final ranked results

The hybrid engine lives in medha-api/internal/search/ and fuses three independent indexes. The RRF constant k=60 is the standard TREC value. Vector search runs under a short per-query timeout so embedding/provider latency cannot dominate recall.

PgFTS (pgfts.go)

PostgreSQL tsvector/ts_rank over a GIN index.

TSQuery expander (LLM) converts natural language to structured ts_query strings.

Batch-loads provenance for fused vector/graph hits before post-fusion boosts.

Replaced the former hand-rolled BM25 engine.

Vector (vector.go)

Cosine similarity via Python /embed endpoint.

Go HTTP timeout is controlled by EMBEDDING_REQUEST_TIMEOUT_SEC.

Hybrid vector leg is bounded by HYBRID_VECTOR_TIMEOUT_SEC.

Model fingerprint guards against silent reindex mismatch.

8. MCP Tool Surface

The MCP server registers 27+ tools across two files, using Streamable HTTP transport (MCP spec 2025-06-18). Tools delegate directly to the REST layer — no duplicate business logic.

Core tools (tools.go)

smart-search, remember, recall, forget, status, session-history, timeline, profile, patterns, get-context

Extended (tools_extended.go)

Orchestration: plan-create, plan-update, team-list, team-claim

Working: slots-create, slots-get, summarize

Advanced retrieval: facts-search, preferences-search, traces

Entity intelligence: entities-search, graph-traverse

Platform: list-projects, export, diagnose, governance

The wrap() adapter in tools.go converts internal handlers (plain func(ctx, args) (any, error)) to SDK ToolHandler — no handler touches SDK types directly, keeping tool bodies testable without the MCP runtime.

14. Key Design Decisions (ADRs)

#Decision
ADR-0001Queue backend: memory (dev) or rabbitmq (prod), controlled by QUEUE_BACKEND
ADR-0002Ebbinghaus decay constants are config-driven (no recompile needed to tune)
ADR-0003Neo4j is optional; service degrades gracefully when disabled
ADR-0004All REST routes under /v1/agentmemory/ base path
ADR-0005MCP tools delegate to REST logic — no duplicate business logic in MCP layer
ADR-0006Extraction defaults to heuristic (no heavy NLP dependency on cold start)
ADR-0007Prompt injection uses /recall-summary, not raw /smart-search, so noisy operational observations can be filtered without hiding them from debugging tools
ADR-0008Embedding retrieval has explicit time budgets; if the vector leg is slow or unavailable, hybrid search still returns FTS/graph results

15. Decay Model (Ebbinghaus)

Nightly scheduler: for each memory row: age_days = now - created_at (in days) strength *= DECAY_RATE_PER_DAY ^ age_days if strength < DECAY_EVICTION_THRESHOLD: DELETE memory On retrieval (smart-search hit): strength += REINFORCEMENT_ON_RETRIEVAL (0.05) Tier TTLs (before decay even matters): working: 24h episodic: 7d (after which transitions to semantic)

16. Privacy Pipeline

POST /observe arrives with raw hook payload │ ▼ 1. Strip <private>...</private> blocks (most important, runs first) │ ▼ 2. Redact secrets: API keys, JWTs, key=value patterns │ ▼ 3. Remove ANSI escape sequences │ ▼ 4. Set HasSecrets flag → downstream enrichment is skipped │ ▼ 5. Continue to dedup → store → enqueue

Privacy is fail-closed — if any filter step panics, the observation is dropped rather than persisted unsanitized.
